# แผนพัฒนา

เป้าหมาย: POS ที่ใช้งานจริงได้ใน 6 ขั้น ประมาณ 3–4 สัปดาห์แบบทำนอกเวลา ต่อยอดจากต้นแบบใน `prototype/`
สถานะปัจจุบัน: **ขั้น 0 — เตรียมตัว** (อุปกรณ์ยืนยันแล้ว รอซื้อ/รอของ)

## ภาพรวมระบบ

แคชเชียร์กดออเดอร์บนแท็บเล็ต → ระบบคิดเงินและบันทึกบิลในเครื่อง → ส่งตั๋วเป็นภาพไปปริ้นเตอร์ผ่าน USB → ปริ้นเตอร์พิมพ์ ตัดกระดาษ และเปิดลิ้นชักเมื่อจ่ายเงินสด ทั้งหมดทำงานได้โดยไม่ใช้เน็ต

| ส่วน | ใช้อะไร | ทำไม |
|---|---|---|
| หน้าจอขาย | เว็บแอป (HTML/CSS/JS ล้วน) ต่อยอดจากต้นแบบ | กติกาและรายงานทำและเทสต์แล้ว |
| ติดตั้งบนแท็บเล็ต | PWA บนหน้าจอโฮม หรือแอป Android ห่อเว็บ (Capacitor) | เลือกตามผลทดสอบขั้น 1 |
| สั่งพิมพ์ | ESC/POS raster ผ่าน WebUSB (หรือ plugin USB ของแอป Android) | ตั๋วออกทันที ภาษาไทยตรงกับจอ |
| ลิ้นชัก | คำสั่ง ESC p ผ่าน RJ11 ของปริ้นเตอร์ | เตรียมไว้ ซื้อลิ้นชักทีหลังเสียบใช้ได้เลย |
| เก็บข้อมูล | IndexedDB + ส่งออก CSV ทุกวัน | ทนกว่า localStorage ไม่ต้องมีเซิร์ฟเวอร์ |
| ชำระเงิน | เงินสด / QR PromptPay ใส่ยอด (EMVCo) / ไทยช่วยไทย พลัส | QR สร้างได้แม้ไม่มีเน็ต ลดโอนผิดยอด |
| เก็บโค้ด + โฮสต์ | GitHub + GitHub Pages | ฟรี มีประวัติเวอร์ชัน ย้อนกลับได้ |

| ขั้น | ทำอะไร | ใครทำ | เสร็จแล้วได้อะไร | เวลา |
|---|---|---|---|---|

| 4. ทดลองใช้จริง | ใช้คู่กับจดมือ เทียบยอดกับเงินจริงทุกวัน | Tee + ทีม, Claude แก้บั๊ก | ยอดตรงกันหลายวันติด | 1–2 สัปดาห์ |

## เช็กลิสต์ทดสอบฮาร์ดแวร์วันแรก (ขั้น 1)
เปิด `printer-test/index.html` ผ่าน https (GitHub Pages) บนแท็บเล็ต หน้านั้นมีเช็กลิสต์นี้ให้กดผ่าน/ไม่ผ่าน และปุ่มคัดลอก log ส่งให้ Claude
ข้อ 4–5 ตัดสินว่าใช้ PWA พอ หรือต้องทำแอป Android
- [ ] อัปเดต Android และ Chrome เป็นล่าสุด
- [ ] กด Feed ค้างตอนเปิดปริ้นเตอร์ → พิมพ์หน้าทดสอบของเครื่อง
- [ ] ต่อปริ้นเตอร์ผ่าน OTG → แท็บเล็ตเจออุปกรณ์ USB
- [ ] เปิดหน้าทดสอบใน Chrome → กด "เชื่อมปริ้นเตอร์" → เลือกเครื่องได้ (WebUSB)
- [ ] พิมพ์ตั๋วตัวอย่าง ภาษาไทยอ่านออก เลขออเดอร์ใหญ่ชัด
- [ ] ตัดกระดาษอัตโนมัติ และตัดแยกใบเสร็จกับตั๋วครัว
- [ ] ถอดสาย/ปิด-เปิดแอป แล้วยังพิมพ์ได้ (ต้องเลือกเครื่องใหม่ทุกครั้งไหม)
- [ ] โหมดเครื่องบิน: เปิดแอป ขาย พิมพ์ได้
- [ ] ถ่ายรูปตั๋วส่งให้ Claude ปรับขนาด/เลย์เอาต์

## ความเสี่ยงและแผนสำรอง
| ความเสี่ยง | แผนสำรอง |
|---|---|
| WebUSB บน Chrome Android ใช้กับปริ้นเตอร์ไม่ได้ | ทำแอป Android ห่อ (Capacitor + USB serial/printer plugin) ติดตั้งเองไม่ต้องผ่าน Store (+2–3 วัน) |
| แท็บเล็ตไม่รองรับ OTG | ลองที่ร้านก่อนซื้อ หรือใช้ปริ้นเตอร์ต่อ LAN |
| ข้อมูลหาย | CSV ทุกวัน + ภายหลังเพิ่มสำรองขึ้นคลาวด์อัตโนมัติเมื่อมีเน็ต |
| ปริ้นเตอร์เสียกลางงาน | ขายต่อได้ แสดงเลขออเดอร์บนจอ พิมพ์ซ้ำทีหลังจากแท็บบิล |
| คิดเงินผิดจากบั๊ก | เทสต์อัตโนมัติทุกกติกา + ช่วงทดลองใช้คู่จดมือ |
| อัปเดตแล้วพัง | อัปเดตนอกเวลาขาย, ย้อนเวอร์ชันจาก GitHub |

## ไอเดียที่พิจารณาแล้วและพักไว้
- ส่งตั๋วเข้า LINE OA ของครัว: ต้องมีเน็ต + เซิร์ฟเวอร์ + โควตาฟรีแค่ 300 ข้อความ/เดือน (Basic ฿1,280/เดือน) → พักไว้
- จอครัวแบบเว็บ (Kitchen Display): ทางเลือกที่ดีกว่า LINE ถ้าอนาคตต้องการ แต่ต้องมีเน็ตและเซิร์ฟเวอร์เล็ก
- ปริ้นเตอร์สติกเกอร์ติดถ้วย: อาจดีกว่าตั๋วครัว ถ้าถ้วยสลับบ่อย
